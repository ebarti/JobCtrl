Option C: filter panel

Inspired by AG Grid and Material React Table: the table stays dense, while a side panel holds richer boolean, text, and multi-select controls without stretching header rows.

Best when filters become complex or saved presets matter. Open mockup

Spike recommendation

  • Keep TanStack Table as the table engine. It already supports controlled sorting and column filter state, including server-side filtering when needed.
  • Use an OpenStatus-style filter schema or a local equivalent so Jobs, Discovery, Runs, and Artifacts do not each invent filter state differently.
  • For the Source registry specifically, prototype Option B first: filters on the column headers match the Google Sheet mental model and make all tags first-class columns.
