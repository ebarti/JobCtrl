# 12-01 Dependency And Config Cleanup

## Goal

Remove obsolete visual-migration dependency/config remnants only where audits prove they are unused.

## Tasks

- Audit `lucide-react` source imports, package dependency entries, and lockfile entries.
- Remove `lucide-react` from `apps/web/package.json` and `pnpm-lock.yaml` if the source import audit is clean.
- Re-run the dependency audit to prove no `lucide-react` package or lockfile entries remain.
- Keep `@tabler/icons-react` as the icon dependency target.

## Threat Model

- **Sensitive data exposure:** None expected; this phase reads package/config/docs only.
- **Supply-chain risk:** Dependency removal must be reflected in lockfile through `pnpm`, not manual package drift.
- **Availability risk:** Removing the dependency while a hidden import remains would break web build; source audit and `pnpm web:check` are required.

## Verification

- `rg "from \\\"lucide-react\\\"|from 'lucide-react'|lucide-react" apps/web/src apps/web/package.json pnpm-lock.yaml`
- `corepack pnpm web:check`
- `corepack pnpm web:build`
