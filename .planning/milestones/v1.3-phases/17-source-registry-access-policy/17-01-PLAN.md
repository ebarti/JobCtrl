# 17-01 Compensation Source Policy Contract And API

<objective>
Add the backend and shared TypeScript contract for a deterministic compensation source policy registry. The API must expose inspectable source-access metadata without network I/O and must keep Levels.fyi and Glassdoor unavailable unless explicit safe access gates are configured.
</objective>

<tasks>

## Task 1: Shared Contract

**type:** implementation
**files:**
- `packages/contracts/src/schemas.ts`
**action:**
- Add compensation source literal alphabets and DTO interfaces for source id, display name, source type, access mode, availability, license status, terms/source URL, freshness policy, attribution requirement, supported fields, disabled reason, configured flag, Europe coverage, and safe notes.
- Export `CompensationSourceRegistryResponse` as `{ ok: true; sources: CompensationSourcePolicySummary[] }`.
- Do not add credential, raw provider payload, local path, private account, scraped page, or raw salary data fields.
**verify:**
- TypeScript consumers can import the new response and summary types from `@jobhunter/contracts`.
- DTO fields cover every SRC-01 field.
**done:**
- Contract definitions compile and are additive.

## Task 2: Deterministic Registry Service

**type:** implementation
**files:**
- `apps/api/src/compensation-source-policy.ts`
**action:**
- Create a static source registry for posted salary text, Eurostat SES, ESCO, Spain INE, Levels.fyi, and Glassdoor.
- Implement `listCompensationSources(env?: NodeJS.ProcessEnv): CompensationSourceRegistryResponse`.
- Enforce exact safe gates:
  - Levels.fyi is available only when `JOBHUNTER_LEVELS_FYI_ACCESS_MODE` is one of `licensed_api`, `licensed_data_feed`, or `enterprise_mcp` and `JOBHUNTER_LEVELS_FYI_EUROPE_COVERAGE` is `1` or `true`.
  - Glassdoor is available only when `JOBHUNTER_GLASSDOOR_ACCESS_MODE` is `partner_api` or `written_permission`.
  - Missing or partial configuration leaves the source unavailable with a disabled reason.
- Keep the function pure and network-free; it may read only the provided env object.
**verify:**
- Static public sources are inspectable by default.
- Partial licensed-source configuration does not make Levels.fyi or Glassdoor available.
**done:**
- Service returns deterministic policy metadata and performs no provider calls.

**type:** implementation

**verify:**

**done:**
