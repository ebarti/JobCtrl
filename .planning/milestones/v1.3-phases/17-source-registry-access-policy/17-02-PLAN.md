# 17-02 Compensation Source Policy UI

<objective>
Expose the compensation source policy registry through the frontend architecture so users can inspect Europe-first public baselines and disabled licensed seams from Settings without entering the later Jobs salary triage scope.
</objective>

<tasks>

## Task 1: Frontend Port And Operations Hook

**type:** implementation
**files:**
- `apps/web/src/shared/adapters/local/FetchApiClientAdapter.ts`
- `apps/web/src/shared/ports/ApiClientPort.ts`
- `apps/web/src/contexts/operations/compensationKeys.ts`
- `apps/web/src/contexts/operations/queryKeys.ts`
- `apps/web/src/contexts/operations/types.ts`
- `apps/web/src/contexts/operations/hooks/useCompensationSourcePolicyQuery.ts`
**action:**
- Add `compensationSources()` to the API port.
- Add the `FetchApiClientAdapter` delegation to `JobHunterApiClient.compensationSources()`.
- Add an Operations-owned tenant-scoped `compensationKeys.sources(tenantId)` key and export it through Operations query keys.
- Add an Operations read hook that calls the API port and uses the Operations compensation query key.
- Re-export compensation source types through Operations types.
**verify:**
- Hook compiles and does not call the API client directly outside the port.
- Query key shape starts with `["tenant", tenantId, "operations", "compensation", ...]`.
**done:**
- Frontend reads compensation source policy through Operations.

## Task 2: Read-Only Scoring Context Panel

**type:** implementation
**files:**
- `apps/web/src/contexts/scoring/components/CompensationSourcePolicyPanel.tsx`
- `apps/web/src/contexts/scoring/index.ts`
- `apps/web/src/routes/settings.index.tsx`
**action:**
- Add a scoring-owned `CompensationSourcePolicyPanel` component that consumes the Operations hook.
- Compose the panel into `/settings` in the settings index route below the existing profile `SettingsPanel`.
- Render source name, source type, availability, license status, access mode, freshness policy, attribution requirement, supported fields, and disabled reason.
- Use existing card/banner/tag/table styling and avoid nested cards.
**verify:**
- Users can inspect source policy on Settings.
- Levels.fyi and Glassdoor render as disabled/unavailable by default with explicit reasons.
- Public Europe baselines are visually distinct from licensed seams.
**done:**
- Settings includes a narrow source policy inspection surface.
