# 20-02 Plan: Additive API Contract And Realtime Invalidation

<objective>
Expose projection-backed compensation summary/audit fields on job list/detail responses and route safe compensation update events through Operations/SSE invalidation.
</objective>

<tasks>

## Task 1: Add contracts and read-model mapping

type: implementation
files:
  - `packages/contracts/src/schemas.ts`
  - `apps/api/src/read-model.ts`
action:
  - Add `JobCompensationSummary` and `JobCompensationAudit` contract types.
  - Add optional/additive `compensationSummary` to `JobSummary`.
  - Add `compensationAudit` to `JobDetail`.
  - Deserialize projection JSON in `rowToJobSummary` and `getJobDetail`; do not compute or parse from raw fields in the API read path.
verify:
  - `corepack pnpm --filter @jobhunter/contracts check`
  - `corepack pnpm api:check`
acceptance_criteria:
  - Job list/detail consumers receive structured compensation data from projection rows.
  - Invalid or absent projection JSON returns `null`, not a thrown request.
  - `salary` remains present and unchanged.
