| Boundary | Description |
|----------|-------------|
| API `JobDetail` -> drawer | Compensation audit data becomes detailed visible evidence. |
| Compensation audit -> Apply audit adjacency | Warning-only compensation evidence sits next to readiness/apply concerns without becoming a gate. |
| Disclosure content -> accessibility tree | Hidden/detail content must remain keyboard and screen-reader accessible. |
