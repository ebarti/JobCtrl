Affected requirements: SRC-04, SRC-05, SRC-06, EST-06, QA-04.

The local `compensation-refresh --observations-json` path can import provider-labeled rows for `levels_fyi` and `glassdoor` when those rows are supplied locally. This matches the milestone requirement for permitted/manual local reported-observation imports and no network fetch/scrape/cache path was found. The residual risk is operational: real imported rows must be authorized before import because the importer does not independently verify provider permission at import time.
