# 19-02 Plan: Market Estimate Inspection API

<objective>
Expose persisted Europe public market estimates through a narrow read-only TypeScript contract and API endpoint without changing job list/detail projections, ranking, filtering, scoring, apply readiness, or Jobs UI.
</objective>

<tasks>

## Task 1: Add shared market-estimate DTOs and API client method

type: implementation
files:
  - `packages/contracts/src/schemas.ts`
  - `packages/api-client/src/client.ts`
action:
  - Add string unions and interfaces for market estimate state, source IDs, confidence factors, source snapshots, warning codes, reason codes, and response shape.
  - Model `MarketCompensationEstimate` as explicit state arms: non-range arms carry reasons/factors/sources/warnings and no range fields; `estimated_range` carries currency, period, component, minimum/maximum, confidence, factors, sources, and warnings.
  - Add `MarketCompensationEstimateResponse` with `recordStatus: "recorded" | "not_requested"`.
  - Add `marketCompensationEstimate(jobKey)` to `@jobhunter/api-client`.
verify:
  - `corepack pnpm --filter @jobhunter/contracts check`
  - `corepack pnpm --filter @jobhunter/api-client check`
acceptance_criteria:
  - Contracts make precise range fields unavailable on non-`estimated_range` arms.
  - Contracts expose only safe public source identifiers.
  - API client uses the route `/v1/jobs/:jobKey/compensation/market`.

## Task 2: Add read-only API mapper and route

type: implementation
files:
  - `apps/api/src/market-compensation-estimates.ts`
  - `apps/api/src/server.ts`
action:
  - Add a read-only mapper that checks `jobs` first, returns `null` for unknown jobs, returns `not_requested` when the market table or row is absent, and maps persisted rows to the contract DTO.
  - Parse JSON safely for sources, factors, warnings, and reasons, dropping unknown codes/unsafe entries.
  - Add `GET /v1/jobs/:jobKey/compensation/market` next to the posted compensation route using `withDb`, not `withWritableDb`.
  - Do not parse, estimate, backfill, persist, refresh projections, or call external providers from the GET path.
verify:
  - `corepack pnpm --filter @jobhunter/api exec vitest run test/market-compensation-estimates.test.ts`
acceptance_criteria:
  - Unknown jobs return `404`.
  - Existing jobs with no table/row return `recordStatus: "not_requested"` and do not write any rows.
  - Recorded `unsupported`, `source_unavailable`, `insufficient_evidence`, and `estimated_range` states serialize correctly.
  - Serialized responses omit private descriptions, raw provider payloads, credentials, local paths, Glassdoor, Levels.fyi, and U.S. source labels.
