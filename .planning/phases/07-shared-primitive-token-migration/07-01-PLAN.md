<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| synthetic story/test data -> rendered primitive | Storybook and Vitest render fixture text that must not contain sensitive local JobHunter data. |
| test runner -> local browser/runtime | Storybook and Vitest may drive browser-like UI behavior but must not trigger product automation. |
| shared/ui -> app/domain modules | Shared primitives must not import contexts, views, API clients, query hooks, EventSource, localStorage, or domain status helpers. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01-I | Information Disclosure | `data-table*.tsx`, `toast*.tsx`, stories/tests | mitigate | Use synthetic rows, run IDs, and messages only; do not copy profile, resume, generated material, logs, DB rows, job URLs, secrets, or OAuth data. |
| T-07-01-T | Tampering | Storybook/Vitest QA | mitigate | Run only Storybook/Vitest/static checks; do not run auto-apply, browser submission, mailbox scanning, real material generation, destructive profile/database actions, or worker-backed jobs. |
| T-07-01-B | Tampering | `apps/web/src/shared/ui` imports | mitigate | This plan does not add cross-boundary imports; Plan 07-05 runs the blocking boundary scan. |
| T-07-01-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs are allowed in this plan; if an install appears necessary, stop and reroute through package legitimacy review. |
</threat_model>
