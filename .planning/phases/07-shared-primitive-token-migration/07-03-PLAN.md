## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| synthetic story data -> open overlays | Story fixtures render content inside portals and overlays; fixture content must be non-sensitive. |
| Storybook browser runner -> local app | Browser automation exercises stories only, not real product routes or worker-backed jobs. |
| shared/ui stories -> app/domain modules | Overlay stories must not import bounded contexts, views, API clients, query hooks, local storage, EventSource, or route modules. |

</threat_model>
