# Phase 8 Plan 02 - Tabler Icon Migration

## Goal

Migrate user-visible shell and shared chrome affordance icons from `lucide-react` to `@tabler/icons-react` without changing action meaning, accessible labels, or control dimensions.

## Requirements Covered

- LAYOUT-01: shell/chrome controls adopt the preset visual language.
- LAYOUT-03: user-visible lucide icons are migrated or explicitly mapped to Tabler equivalents.

## Tasks

1. Replace shell icon imports.
   - `ThemeToggle.tsx`: `Moon` -> `IconMoon`, `Sun` -> `IconSun`.
   - Preserve `aria-label`, `aria-hidden`, button type, visible `theme` text, and toggle behavior.

2. Replace shared UI affordance imports.
   - `Search` -> `IconSearch`.
   - `Check` -> `IconCheck`.
   - `ChevronDown` -> `IconChevronDown`.
   - `ChevronUp` -> `IconChevronUp`.
   - `ChevronRight` -> `IconChevronRight`.
   - `Circle` -> `IconCircle`.
   - `Copy` -> `IconCopy`.
   - `X` -> `IconX`.
   - `Filter` -> `IconFilter`.
   - `SortAsc` -> `IconSortAscending`.
   - `SortDesc` -> `IconSortDescending`.
   - `TableProperties` -> `IconTable`.

3. Preserve primitive behavior while swapping icons.
   - Keep Radix/cmdk primitive composition unchanged.
   - Preserve class names, dimensions, focus states, close labels, row activation, sort labels, filter labels, and clipboard port usage.
   - Do not add inline SVGs or new icon wrapper abstractions unless there is repeated complexity to remove.

4. Decide Priority B icon scope after Priority A compiles.
   - Migrate obvious action icons if the change is import-only and covered by existing tests.
   - Defer domain/status icons when the icon implies product status tone or would require domain behavior review.
   - Record every retained lucide import in the Phase 8 icon audit with file, icon, reason, and owning later phase.

5. Keep dependency cleanup out of this plan.
   - Do not remove `lucide-react` from `apps/web/package.json` unless all imports are gone and Phase 11 cleanup is explicitly pulled forward.

## Acceptance Criteria

- Shell and shared primitive user-visible affordance icons import from `@tabler/icons-react`.
- Accessible labels and decorative `aria-hidden` usage are preserved.
- Control dimensions and class names remain stable.
- Remaining `lucide-react` imports are either absent or explicitly documented as deferrals.

## Risks And Guards

- Risk: Tabler icon names differ from assumptions. Guard: verify exports from the installed `@tabler/icons-react` package before editing.
- Risk: icon-only controls lose names. Guard: keep existing `aria-label` and `sr-only` text untouched.
- Risk: domain icon migration changes perceived status semantics. Guard: defer domain/status tone-sensitive icons to Phase 9 or Phase 11 and document the reason.
