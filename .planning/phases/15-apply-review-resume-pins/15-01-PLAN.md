# 15-01 Resume Pin Component And Layout

## Goal

Make the rendered resume the primary Apply Review object and add artifact-backed claim pins beside it.

## Tasks

- Add a context-owned `ResumeAuditPins` component under `contexts/materials/components`.
- Fetch artifact detail through `useArtifactDetailQuery`.
- Derive pin rows from `bulletProvenance`, falling back to `annotatedChanges` when no bullet rows exist.
- Render selectable pins and a detail panel with source text, tailored text, transform, controls, evidence IDs, requirement IDs, keywords/signals, rationale, and risk/lifecycle facts.
- Update `ApplyReviewView` to place `ResumePreview` first in a `Rendered resume audit` region and compose `ResumeAuditPins` beside it.
- Move the full `ArtifactTailoringInspector` below the resume-centered pin surface.
- Add responsive CSS using grid/container-aware constraints.
