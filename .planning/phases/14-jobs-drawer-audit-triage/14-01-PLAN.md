# 14-01 Drawer Audit Triage Component

## Goal

Add the top-of-drawer audit triage section that explains ranking, readiness, blockers, eligibility concerns, and handoff to Apply Review.

## Tasks

- Create a `JobAuditTriage` component in `apps/web/src/views/jobs/`.
- Render it in `JobDetailDrawer` immediately after `JobOverview`.
- Format ranking evidence from `detail.job.scoreBreakdown`, `scoreKeywords`, `scoreReasoning`, `scoreTrace`, and `scoreCriteria`.
- Format readiness/blocker evidence only from `detail.applyAudit`.
- Add an Apply Review handoff link to `/apply-review`.
- Add scoped CSS for dense two-column drawer layout, wrapped fact tags, and mobile collapse.

## Threat Model

- **Misleading readiness:** Do not derive status from stage/material fields in the component.
- **Sensitive data exposure:** Use only bounded existing score/audit facts already in read models; do not expose raw prompts, profiles, or local paths.
- **Action safety:** The handoff link must not trigger apply automation.
